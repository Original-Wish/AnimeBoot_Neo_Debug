# 组件目录用途

assets供制作器离线使用，不会整体复制到ESP。当前锁定资源157项，两档BIOS各46个模块；默认和备用是用户可选的一对完整实现，不按版本号大小自动认定备用无用。

| 路径 | 目的 | 部署情况 |
| --- | --- | --- |
| assets/fedora/*.efi、bzImage | 官方签名启动二进制 | 按平台/动画状态部署，GRUB两档只装所选一档 |
| kernel.config、modules.builtin | 核对官方内核的编译配置与内建模块 | 制作参考，不写启动分区 |
| unicode.pf2 | Legacy GRUB字体 | 仅Legacy |
| assets/grub/i386-pc*/*.mod | mkimage显式模块与依赖 | 合并进core/grub2.lnx，不逐个安装 |
| kernel.img | GRUB核心模板 | 制作时生成静默副本再链接 |
| diskboot.img | i386-pc核心的磁盘加载模板 | mkimage输入，不单独部署 |
| lzma_decompress.img | 核心压缩解码模板 | mkimage隐式输入，不能按moddep列表删除 |
| lnxboot.img | Linux启动协议包装 | 与core.img组合成grub2.lnx |
| moddep.lst及其它lst、modinfo.sh | 依赖/能力索引及构建信息 | 制作/开发参考，不单独部署 |
| gdb_helper.py | 对应GRUB调试辅助源码 | 开发参考，不运行于目标机器 |
| grub-mkimage.exe、grub-script-check.exe | 制作核心与检查配置语法 | Windows制作阶段运行 |
| grldr | 上游GRUB4DOS输入 | 生成文件桥后部署为bootmgr |
| neo_vbe.c | 本工程BIOS显示交接源码 | 生成neo_vbe.mod，嵌入核心 |
| assets/legacy/mbr.asm、mbr.bin | 微型MBR源码与512字节模板 | Legacy只提交前440字节 |
| assets/linux/*.c、*.h、build_player_mt.sh | PID1/播放器源码、显示接口和自有字形 | 开发/重建使用，不单独安装 |
| assets/linux/*_x86_64 | 静态Linux程序 | 动图initramfs内 |
| app_icon/character素材 | 应用图标及默认画布素材 | 可见画布对象合成进背景 |
| components.lock.json、grub-pairs.json | 字节完整性和配对版本清单 | 制作/校验使用 |

## BIOS模块逐项

两目录分别对应2.12-64.fc44和2.12-56.fc44，模块名相同不代表二进制可互换。

| 模块 | 功能 |
| --- | --- |
| `acpi.mod` | 所选模块的递归依赖；精确调用关系见同目录moddep.lst及对应SRPM源码 |
| `biosdisk.mod` | BIOS磁盘服务读取普通文件 |
| `bitmap.mod` | 位图处理 |
| `bitmap_scale.mod` | 位图缩放 |
| `boot.mod` | 通用启动入口 |
| `bufio.mod` | 缓冲输入 |
| `chain.mod` | 链式加载入口 |
| `configfile.mod` | 执行配置文件 |
| `crypto.mod` | 密码/校验公共框架 |
| `datetime.mod` | 日期/时间公共接口；normal的依赖，并不意味着启用按天轮换 |
| `disk.mod` | 磁盘公共库，供磁盘访问相关模块使用 |
| `echo.mod` | 文本/空输出 |
| `extcmd.mod` | 扩展命令参数 |
| `fat.mod` | FAT16/FAT32文件系统 |
| `font.mod` | PF2字体解析 |
| `fshelp.mod` | 文件系统公共辅助 |
| `gettext.mod` | 消息本地化接口 |
| `gfxmenu.mod` | 图形主题/倒计时控件 |
| `gfxterm.mod` | 图形终端 |
| `halt.mod` | 停止 |
| `jpeg.mod` | JPEG解码 |
| `linux.mod` | Linux内核加载协议 |
| `loadenv.mod` | 加载/保存GRUB环境块 |
| `mmap.mod` | 内存映射与可用内存管理，内核加载/内存搬移所需 |
| `neo_vbe.mod` | 本工程VBE参数交给Linux |
| `net.mod` | normal模块的上游网络框架依赖；保留该依赖不等于启用网络启动，不含额外网卡驱动 |
| `normal.mod` | 普通菜单与命令解释环境 |
| `ntfs.mod` | NTFS文件系统 |
| `ntldr.mod` | 加载Windows bootmgr |
| `part_msdos.mod` | MBR分区表识别 |
| `png.mod` | PNG解码 |
| `priority_queue.mod` | 优先队列 |
| `reboot.mod` | 重启 |
| `relocator.mod` | 低层内存搬移 |
| `search.mod` | 搜索框架 |
| `search_fs_file.mod` | 按文件搜索支持 |
| `search_fs_uuid.mod` | 按文件系统UUID定位 |
| `search_label.mod` | 按卷标搜索支持 |
| `sleep.mod` | 外层静图等待 |
| `terminal.mod` | 终端选择 |
| `test.mod` | 条件判断 |
| `trig.mod` | 三角函数查表，供图形菜单圆形控件计算使用 |
| `vbe.mod` | BIOS VBE显示 |
| `video.mod` | 通用视频接口 |
| `video_colors.mod` | 图形菜单颜色名称与数值转换 |
| `video_fb.mod` | 帧缓冲抽象 |

`moddep.lst`是递归依赖依据；精简时还必须保留mkimage隐式模板。当前内置没有用到的网络/额外文件系统/总线模块不随工程打包。
索引中的可选模块名不代表文件必须全部存在；当前制作器只使用显式模块闭包，不在启动时让GRUB扫描一个外置模块目录。
