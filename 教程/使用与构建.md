# 使用与构建

## 开发与运行

在 Windows 安装 Python 3.8.x 32位（推荐3.8.10），进入工程根目录：

```powershell
python -m venv .venv
.venv\Scriptsctivate
python -m pip install -r requirements-build.txt
python app.py
```

界面能在32位Python运行不代表支持32位UEFI；随包EFI和Linux内核是x86-64。Legacy同样需要能够执行x86-64内核的CPU。安装需管理员权限，普通编辑无需写启动分区。

## 构建可执行程序

```powershell
python build.py
python build.py --onefile
```

目录版：`dist/AnimeBoot Neo Debug/AnimeBoot Neo Debug.exe`；单文件版：`dist/single/AnimeBoot Neo Debug.exe`。
不要只复制目录版的EXE；它需要旁边的数据及DLL。单文件版运行时会解包资源到临时目录，因此首次启动/杀毒扫描时间与目录版不同。
`build.py` 用绝对路径传递assets和licenses，spec位于build目录也能找到资源。字体扫描同时覆盖系统与当前用户安装目录。
许可正文会随EXE带入；licenses/sources及SRPM/源码归档不嵌入EXE，也不安装到启动分区；公开分发还须按对应许可提供源码，不因使用单EXE而免除该要求。

## 静图与多画布

中间管理栏选择当前画布；新增使用默认对象，复制保留当前对象，删除只作用于所选画布，至少保留一张。
分辨率、静图时长（0—180秒）、启动设置共用；每张画布可单独设置图片、文字、层序、倒计时类型/位置/颜色。
程序一次只显示和编辑一张。每次开机按A/B/C顺序显示；编辑器当前选择不决定首次开机画布，安装从列表第一张开始。
倒计时支持不显示、圆环、星/心/短线刻度、填充条、贴图条、数字。GRUB动态控件不是视频播放器。
制作期间可切换画布查看/编辑；本次构建读取开始时的快照，编辑变化下次制作生效。新增/删除等管理操作在忙碌期间禁用。

## 静图交接

未开启动图时选择“无感融入”或“清屏过渡”。无感融入且**所有画布均不显示倒计时**时，使用外层等待机制绕开菜单超时清屏。
任一画布有可见倒计时，整套工程均使用菜单倒计时；UEFI无感融入此时可能短暂黑闪再恢复背景。
Legacy的Windows加载器可能重设显示，不能据UEFI结果保证Legacy完全无黑闪。
开启动图时该选择不生效：静图自然结束统一黑屏进入Linux播放器。Esc在静图阶段直接启动Windows；0秒意味着没有该Esc机会。

## 动图与顺序轮换

先选择并启用主动画，再添加最多7个追加素材，合计最多8段；支持视频、动态图片与PNG帧文件夹。全部共用编码、输出尺寸、抽帧和播放设置。
轮换窗口只估算当前编码，计入主动画、全部追加动画、全部静图和启动资源。通过后可启用；相同输入的估算可复用，素材或参数变化必须重估。
估算缓存只存本次程序内存；它不能取代安装时对真实文件和当前空间的检查。
列表已添加但未启用时保存会提醒；选择保持关闭可以保存待用列表。缺失素材不会阻止关闭轮换或删除条目。
轮换独立于静图序号；Esc不推进动画，动画结束后的接力重启也不推进。只按次轮换，不按日期。
调试勾选时，仅动图播放后在播放器画布显示两页诊断，各8秒。安装日志框显示的是Windows制作/安装信息。

## 工程、分享、安装与禁用

“保存当前工程”保留本机素材引用；“分享包”导出工程并打包外部素材。导入的资源目录必须保留，字体/图片的分享权须自行确认。
开始制作先输出普通InstallPayload，之后自动安装；安装遇到可恢复问题可用“制作后期遇到问题点我继续”复用构建结果。
禁用恢复Windows入口后清理本工具所属资源与备份。不要手工删除backup、Windows备份或环境块代替禁用。
程序只接受当前格式，不猜测未知安装/工程的结构。遇到未知所有权记录时会拒绝覆盖。

## 自动检查与打包源码

```powershell
python -m unittest discover -s tests -v
python tools/package_source.py --out ../AnimeBoot_Neo_Debug_2610.3_工程.zip
```

测试使用临时目录及mock Windows接口。部分原生编译测试依赖Zig/工具链，环境缺少时应明确跳过，不应宣称已测试。
源码打包会检查资源锁、Python语法、ZIP重复成员和CRC，排除缓存、EXE输出及本地工作目录。
